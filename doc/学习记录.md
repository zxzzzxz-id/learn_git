## 8.6 Git 基础操作

- 配置 Git 用户名和邮箱，生成 SSH 公钥连接到 GitHub
- 初始化本地仓库并完成第一次提交
- 修改代码并提交，学习 `git add` 和 `git commit` 的用法
- 创建分支、在分支上修改代码、合并回主分支
- 练习回退操作（`reset`、`revert`），比较两者区别
- 创建 GitHub 远程仓库，练习 push 和 pull

1. 配置 `user.name` 和 `user.email`，生成 SSH 公钥
2. `git init` 初始化仓库
3. `git add .` 暂存所有文件
4. `git commit -m "第一次提交"` 提交
5. 修改 `main.c` 中 `BLINK_TIMES` 为 `5U`
6. `git add Core/Src/main.c` + `git commit -m "将闪烁次数调整为5"`
7. `git checkout -b feature-blink` 创建并切换分支
8. 修改 `DELAY_MS` 为 `300U`，提交
9. `git checkout main` 切回主分支
10. `git merge feature-blink` 合并分支
11. `git reset --hard HEAD~1` 练习回退
12. `git remote add origin` 添加远程仓库
13. `git push -u origin main` 推送到 GitHub

| 命令 | 作用 | 什么时候用 |
|------|------|------------|
| `git init` | 初始化一个 Git 仓库 | 新项目开始时，让 Git 开始追踪这个目录 |
| `git add .` | 把所有改动加入暂存区 | 修改完代码，准备提交之前 |
| `git commit -m "信息"` | 把暂存区的内容保存为一个版本 | add 之后，想把当前改动正式记录下来 |
| `git checkout -b 分支名` | 创建新分支并切换过去 | 要开发新功能但不想影响主分支 |
| `git merge 分支名` | 把指定分支合并到当前分支 | 功能开发好了，要并入主线 |
| `git reset --hard HEAD~1` | 回退到上一个 commit | 上一次 commit 写错了，想撤销 |

```bash
# 第一次提交
git init
git add .
git commit -m "第一次提交"

# 修改并提交
git add Core/Src/main.c
git commit -m "将闪烁次数调整为5"

# 分支操作
git checkout -b feature-blink
# 修改 DELAY_MS 为 300U ...
git add Core/Src/main.c
git commit -m "修改延时为300ms"
git checkout main
git merge feature-blink

# 回退
git reset --hard HEAD~1

# 远程仓库
git remote add origin https://github.com/zxzzzxz-id/learn_git.git
git push -u origin main
```
